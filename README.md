# Campus Accessible Navigation Analysis

A data collection and analysis project evaluating step-free transit efficiency and physical accessibility constraints across campus routes.

---

## Overview

Navigating multi-level campus facilities presents significant bottlenecks for individuals relying on stair-free transit (e.g., wheelchair users, individuals with mobility aids, or service equipment). This project maps, times, and evaluates designated accessible paths between critical campus locations to quantify transit time differentials and identify physical infrastructure constraints.

## Key Features & Scope

* **Stair-Free Route Mapping:** Identified step-free corridors, ramps, and elevator paths connecting high-traffic campus hubs.
* **Empirical Time Tracking:** Timed and recorded transit across baseline and accessible paths to measure routing overhead.
* **Constraint Analysis:** Assessed bottlenecks, detour penalties, elevator transit delays, and architectural barriers affecting path efficiency.

## Methodology

1. **Route Selection:** Defined origin-destination pairs across key campus facilities (classrooms, dining halls, libraries, administrative offices).
2. **Data Collection:** 
   * Timed transit runs along primary pedestrian routes (standard baseline).
   * Timed transit runs along verified step-free/accessible corridors under consistent conditions.
3. **Data Processing:**
   * Normalized route timings and transit distances.
   * Calculated efficiency ratios comparing accessible paths to standard paths.
   * Cataloged physical constraints (door accessibility, elevator wait times, detour margins).
